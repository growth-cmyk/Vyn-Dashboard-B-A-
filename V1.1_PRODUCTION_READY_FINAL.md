## 🚀 Deployment Instructions

### Prerequisites
1. Vercel account with Blob Storage enabled
2. Supabase project with tables created
3. Environment variables configured in Vercel

### Vercel Environment Variables
Set these in Vercel Dashboard → Settings → Environment Variables:

```env
VITE_SUPABASE_URL=https://gmorgozafqwevskcubff.supabase.co
VITE_SUPABASE_ANON_KEY=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
```

**Note**: `BLOB_READ_WRITE_TOKEN` is auto-configured by Vercel

### Deployment Steps

1. **Push to Git**:
```bash
git add .
git commit -m "v1.1 Production Ready - Cloud Persistence Complete"
git push origin main
```

2. **Deploy to Vercel**:
```bash
cd inventory-dashboard
vercel --prod
```

3. **Verify Deployment**:
- Check `/api/blob-upload` endpoint responds
- Upload test file
- Refresh page
- Verify data persists

### Build Configuration (vercel.json)
```json
{
  "buildCommand": "cd inventory-dashboard && npm run build",
  "outputDirectory": "inventory-dashboard/dist",
  "installCommand": "cd inventory-dashboard && npm install",
  "functions": {
    "api/**/*.ts": {
      "runtime": "nodejs20.x"
    }
  }
}
```

## 🐛 Known Issues & Limitations

### Current Limitations
1. **Single User**: No multi-user support (uses 'default_user')
2. **Platform Switching**: Re-hydration runs on mount, not on platform change
3. **File Size**: Limited to 5MB per file
4. **No Versioning**: Latest file overwrites previous

### Future Enhancements
1. Add user authentication and multi-user support
2. Implement file versioning and history
3. Add platform-aware re-hydration on switch
4. Implement retry mechanism for failed uploads
5. Add progress indicators for large files

## 📞 Support & Troubleshooting

### Common Issues

**Re-hydration Not Working**:
1. Check browser console for errors
2. Verify Supabase `file_uploads` table has entries
3. Check Vercel Blob dashboard for uploaded files
4. Verify environment variables in Vercel

**Cloud Backup Failing**:
1. Check `BLOB_READ_WRITE_TOKEN` in Vercel
2. Verify Blob Storage is enabled in Vercel project
3. Check file size is under 5MB
4. Check network tab for API errors

**Statistical ROP Not Persisting**:
1. Verify sales file was uploaded
2. Check console for "Building demand map" message
3. Verify `DataService.loadSalesData()` was called
4. Check ReplenishmentPlanner receives sales data
